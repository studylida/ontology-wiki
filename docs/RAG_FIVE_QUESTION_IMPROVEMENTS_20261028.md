검색된 실험 결과와 같은 출처 계보의 방법·시편 구간을 함께 선택하고, 관계에서 추가되는 근거는 직접 검색 구간과 함께 질문에 대한 관련도를 재정렬하도록 개선했다. 원문 내 수치 불일치를 명시한 구간이 후보에 있으면 보충하고, 실제 생성 문맥에 들어간 구간의 출처 ID를 수치 대조 대상으로 전달한다. 원문, 편집본, 판본, 기존 임베딩은 수정하거나 삭제하지 않았다.

## 평가 방법

## 범위와 한계

방법 보강은 넓은 검색 후보 내 같은 확인된 출처 계보에서만 작동한다. 한 문헌에 여러 실험이 있을 수 있으므로 계보 일치는 동일 시편·실험을 증명하지 않는다. 명시적 수치 차이 보강은 현재 등록된 측정 단위를 인식하는 구간에 한정되며, 검토 표시가 없거나 후보에 들어오지 않은 충돌까지 전수 검출하지 않는다. 서로 다른 시편·시간·단위·실측과 예측의 구분 및 실제 설명은 생성 모델에 의존한다.

관계 근거의 재정렬은 로컬 CrossEncoder의 상대적 순위다. 무관한 구간을 항상 제거하거나 관련 구간을 모두 보존한다는 의미가 아니다. 권한에 맞는 직접 근거가 없거나 재정렬기가 없으면 직접 근거 밖의 관계 근거는 자동 확장하지 않는다. 제거되는 것은 그 답변의 문맥이며 보관된 문헌과 관계가 아니다.

최종 결과와 실제 생성 답변은 `var/rag-evaluation/20261028/five-rag-after/results-verified/`, 앞선 두 확인 실행은 각각 `results/`, `results-final/`에 보존했다. 후보 순위 추적은 반환값을 바꾸지 않고 별도 공급자 호출을 추가하지 않았다. API와 작업자 프로세스를 갱신하고 상태 점검에서 API·웹의 HTTP 정상 응답을 확인했다. 브라우저 화면에서 새 답변을 별도로 생성하지는 않았다.
