# 실제 전처리 경로 연결과 제한 검수

2026-10-27. 이전 `followup-v1`의 HBM2 표3~8 1,864셀 수동 대조와 ALD 표1 개별 교정은 오프라인 결과였다. 이번 변경은 별도의 공통 처리 규칙을 실제 `parse_download` → Docling 결과 검수 → `DocumentRepository.create_source` 경로에 연결했다. 서비스 자료를 등록·교체·승인·활성화하거나 새 임베딩, 답변, 그래프를 만들지 않았다. 현재 작업은 독립 작업 브랜치의 코드와 검수 산출물이다.

## 공통 처리와 적용 범위

- Docling PDF에서 반복되는 숫자 열 병합과 구조가 없거나 빈 표를 감지해 관련 구간을 `excluded`로 보류한다. 표 캡션을 각 표 구간에 유지한다. 자동 복원이나 OCR 일괄 적용은 하지 않는다. 고정 규칙은 다른 형태의 손상 전체를 찾는 정확성 보증이 아니다.
- JATS는 원본 XML을 보존하고 아래·위첨자와 수식을 구분한다. 고유한 원문 캡션과 연결된 구간만 교정한다. 중복, 부호·소수점·첨자 불일치, 지원하지 않는 수식은 추측하지 않고 보류한다. 여러 원문 위치가 있는 구간은 목록을 보존하고 하나를 임의로 대표 위치로 표시하지 않는다.
- XML 완전 문단 대응이 실패하면 수식 밖의 긴 원문 발췌문이 원문과 추출 구간 양쪽에서 각각 유일할 때만 실제 XML XPath를 연결한다. 나머지 위치는 미연결 상태다. XML 위치는 PDF 쪽 번호나 바이트 위치가 아니다.
- 일반 텍스트는 절·문단·표를 유지하고 명시적인 편집 부록을 검색 구간에서 분리한다. 원문과 편집본은 보존한다. 큰 문단·표가 임베딩 입력 한도를 넘을 위험이 있으면 자르지 않고 보류한다. 편집으로 만든 새 판본의 보류는 명시적 검토 승인 전 유지되며 원 추출본은 승인만으로 자동 해제되지 않는다.
- Docling을 설정한 신규 처리에 적용된다. 기본 legacy PDF 처리에는 표 구조 검사 정보가 없다. 기존 서비스 구간은 다시 처리하거나 소급 변경하지 않았다. 이전 캐시를 덮어쓰지 않으며 규칙이 바뀐 결과는 새 캐시 키에 저장한다.

## 대표 사례와 개선에 사용하지 않은 추가 문서

‘통과’는 표에 적은 위치와 확인 항목만을 뜻한다. 다른 페이지·모든 수식·본문의 완전성이나 논문의 과학적 정당성은 확인 불가다. PDF 테스트는 보존된 기존 Docling 추출을 실제 처리 경로에 통과시켰으며 새로운 PDF 추출 또는 OCR을 실행하지 않았다. XML 세 문서는 실제 격리 Docling 작업자로 원본부터 다시 처리했다.

## 검증 기록과 미확인 범위

- 신규 결과와 재현 스크립트: `var/preprocessing-quality-20261027/runtime-path-verification-20261027-v3/`의 `*-actual.json`, `*-actual-pdf.json`, `pdf-observations.json`, `markdown-observations.json`, `check_jats.py`, `check_pdf_cached.py`, `check_markdown.py`. 원본 SHA-256, 출력 구간, XPath·표 참조와 보류 사유가 결과에 남는다. 이전 원본·OCR·개별 편집본은 `run-v4/`, `followup-v1/`와 v2 검증 폴더에 그대로 있다.
- 실제 격리 PostgreSQL과 설치된 격리 Docling 런타임을 이용한 관련 검사 85개가 통과했다. 보류 구간의 저장·승인 동작, 캡션 중복·첨자·숫자·수식 거부, 정상 표, 원문 해시·구간 위치, 기존 캐시 보존과 엔터티 거부를 포함한다. 테스트 DB는 별도 포트에서 만들고 종료했다.
- ALD 32개, b005 7개, c102 2개 XML 문단은 직접 위치가 미연결이다. 위치 일치와 통과 판정은 명시한 샘플에 한정한다. 기존 보관 자료 전체를 재처리하거나 전수 검증하지 않았다. 원본 링크의 온라인 접근 가능 여부는 이번에 검사하지 않았다.
- HBM2 개별 교정과 공통 자동 감지는 별개다. 보류된 신규 결과를 쓸 수 있게 하려면 원문 대조와 별도 편집·승인이 필요하다. 새 OCR 재실행, 서비스 활성화, 원격 전송은 하지 않았다.
