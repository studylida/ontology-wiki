# 기존 RAG와 LightRAG 추가 검색 비교 — 2026-10-27

이 문서는 이전 중단 시점의 기록이다. 이후 사용자가 관련 문헌만 색인해 비교하도록 지시했고, 8문헌·94구간의 동일 조건 대조를 실제로 완료했다. 최신 결과는 [소규모 비교 보고서](RAG_LIGHTRAG_SUBSET_COMPARISON_20261027.md)를 따른다. 전체 색인 불일치가 소규모 비교까지 막는 이유는 아니었다.

결론은 **현재 기존 RAG를 유지하고 LightRAG의 추가 이득은 미확인으로 남긴다**이다. 사용자는 기존 결과·색인을 재사용한 간단한 두 질문 비교만 요청했고 대규모 구축은 하지 않도록 했다. 이번 요청 이후 새 답변·평가기 API 호출이나 새 색인 구축은 시작하지 않았다.

## 재사용한 기존 RAG 결과

현재 승인·검색 가능한 동일 199개 문헌, 같은 생성 모델 `gpt-6-luna`/effort `medium`, 빈 대화 이력으로 이미 실행한 `after-199-graph-off` 두 결과를 사용했다. 여기서 기존 RAG는 전처리·벡터/문자 검색·CrossEncoder·주변 조건 보충을 포함하고 LightRAG만 끈 경로다.

## LightRAG 대조가 어려운 이유

완성되어 활성화된 그래프는 과거 50개 문헌의 snapshot이다. 그 50개와 현재 자료를 대조하면 메타데이터 정정 47개, 현재 판본 교체 2개, 승인 보류 1개이며 정확히 같은 행은 없다. 이를 현재 199개 문헌의 기존 RAG 결과와 비교하면 자료·판본 차이까지 섞인다. 승인 보류나 정정된 출처를 되돌리거나 snapshot 확인을 우회해서 비교하지 않는다.

진행 중이던 199개용 그래프는 새 범위에 맞춰 **52/199개 완료 지점에서 중단**했다. 기존 활성 50개 그래프, 미완성 checkpoint, 원문·판본·비용 기록은 모두 보존했다. API·worker·PostgreSQL은 종료하지 않았다. 중단한 구축의 누적 확인 비용은 $0.532130485이며 기존 인증 실패 1회와 중단 중 7회의 비용은 미확인이다. 이는 두 질문의 처리 비용과 별도이며 그래프 구축의 완성 비용도 아니다.

따라서 동일 자료의 LightRAG 사용 답변·시간·비용이 없고 우열이나 개선율은 계산할 수 없다. 과거 50개 그래프의 검색 연결 시험이나 이전 코드의 답변을 이번 추가 검색의 효과로 대신 보고하지 않는다.

## 권고와 보존 위치

현재 두 질문에서는 기존 RAG가 필요한 핵심 근거를 찾았다. LightRAG를 추가했을 때 더 정확해진다는 증거는 아직 없으므로 **기존 RAG 유지**를 권한다. 이는 성능 차이가 작다는 실측 결론이 아니라 추가 복잡도와 비용을 정당화할 이득이 확인되지 않았다는 판단이다.

재현 기록은 private 경로 `var/rag-evaluation/20261027/after-199-graph-off/{results,manual-review}.json`, `old50-vs-current199-manifest-check.json`, `cost-ledger-current-results.json`에 있다. 구축 중단 기록은 `var/lightrag/builds/52b24f511d8c4ebd8f7a753041ebe981/scope-stop-report.json`에 있다. 파일 삭제·원격 push·배포·컴퓨터 종료는 수행하지 않았다.
