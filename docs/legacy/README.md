# 이전 구현의 설계 기록

이 폴더는 기준 커밋 `8e7fb58bd0c051fff99ab97a39278ef2bdc5ba0a`의 화면·도메인·실험 문서를 보존합니다. 현재 제품의 실행 지시나 승인된 설계로 사용하지 않습니다. 최신 기준은 루트 README, `docs/ARCHITECTURE.md`, `docs/design/CONTRACT.md`입니다.

이전 위키·비교·플로팅 챗봇·검토 편집기 및 Redis 경로는 새 실행 코드에서 제거했습니다. 원문, 기존 seed 데이터, 과거 개념/관계/검토 기록을 코드와 같은 이유로 삭제하지 않습니다. `backend/seeds/`의 원래 상태명·golden/verified 표현은 당시 데이터 그대로 보존된 것이며 새 시스템의 실제 문헌 승인 또는 전문가 인증을 뜻하지 않습니다.

기존 실행 코드는 Git의 기준 커밋으로 복원할 수 있습니다. 새 서비스에서 호환 서버나 예전 탭을 함께 운영하지 않습니다. 운영 전환은 별도 승인과 실제 데이터 대조가 필요한 미수행 작업입니다.
