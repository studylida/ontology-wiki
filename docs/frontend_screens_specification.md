## 1. 글로벌 탑바 (Top Bar) & 시스템 설정 팝업창

### 1.1 상단 탑바 (Top Bar)
- **화면 위치**: 화면 최상단 상시 고정 (Sticky Header)
- **화면 구성**:
  - 좌측: 브랜드 로고 (`Industry Wiki: 반도체 온톨로지`) + 4대 작업실 전환 탭:
    - `📖 위키 본문` / `⚖️ 기술 대안 비교분석` / `✍️ 검토·승인 센터` / `📑 외부 문헌·백서 조사`
  - 우측: `Cmd+K 전역 검색 버튼` + `⚙️ 설정 버튼` (상태 인디케이터 닷 포함)
- **기대 기능 (Requirements)**:
  1. **작업실 전환**: 4대 탭 클릭 시 메인 화면과 좌측 사이드바가 Transitions.dev 기반으로 부드럽고 즉각 전환된다.
  2. **작업 상태 보존**: 탭을 자유롭게 이동해도 각 화면에서 입력 중이던 내용(비교분석 쿼리, 검토 에디터 편집문 등)이 초기화되지 않고 유지된다.
  3. **전역 검색 트리거**: 검색 버튼을 누르거나 키보드 `Cmd+K` / `Ctrl+K`를 누르면 즉시 검색 모달을 띄운다.
  4. **설정 트리거 및 직관적 상태 확인**: `⚙️ 설정` 버튼 클릭 시 설정 팝업창을 연다. API Key가 등록되어 있으면 설정 아이콘 옆 닷에 **초록 불**이 켜져 연동 상태를 한눈에 확인할 수 있다.

### 1.2 [신규] 시스템 설정 팝업창 (Settings Modal)
- **화면 위치**: 탑바 `⚙️ 설정` 버튼 클릭 시 중앙 팝업 (`#settings-modal`, Transitions.dev Modal open/close)
- **화면 구성**:
  - 상단: 타이틀 (`시스템 환경 설정`) + 키 등록 상태 배지 + 닫기 버튼
  - 상단 알림 배너: 신규 온톨로지 배포 알림 및 동기화 버튼
  - 섹션 1: 상용 AI API Key 보안 설정 (로컬 격리 보관)
  - 섹션 2: 런타임 환경설정 (서버 주소, 모델, 기본 열람 깊이, 테마)
  - 하단: 닫기 버튼
- **기대 기능 (Requirements)**:
  1. **API Key 보안 입력 및 저장**:
     - **Google Gemini API Key**: 시맨틱 임베딩(`text-embedding-005`) 및 지식 인덱싱용.
     - **OpenAI API Key**: 메인 인과 추론(`GPT-6.1 Sol / GPT-4o`)용.
  2. **로컬 보안 격리**: 브라우저 `sessionStorage`에만 보관하며 외부나 쿠키에 평문 전송을 엄격히 금지한다.
  3. **비식별화 마스킹**: 키 저장 즉시 `AIzaSy...*****(끝 4자리)` 형태로 가려지고 `👁️ 보기/가리기`, `✏️ 키 수정`, `🗑️ 키 삭제`를 지원한다.
  4. **신규 온톨로지 배포 알림 및 캐시 새로고침**:
     - 서버에 새로운 온톨로지 버전(v1.3 등)이 배포되었을 때 `📢 신규 온톨로지(v1.3)가 배포되었습니다. [지금 최신 데이터 동기화]` 배너를 노출하고, 클릭 시 로컬 캐시를 비우고 최신 지식을 동기화한다.
  5. **백엔드 서버 주소 (API Base URL) 선택**:
     - `로컬 개발 (localhost:8000)` / `사내 스테이징` / `팹 라인 운영망 (Production)` 드롭다운 선택.
  6. **지식 공백(Gap) 감지 임계값**:
     - 사용자별 편차로 인한 지식 파편화를 막기 위해 클라이언트 임의 조절을 금지하고, `사내 표준 고정 정책 (0.35)`으로 읽기 전용 표시한다.
  7. **독자 기본 열람 깊이 프리셋**:
     - 신규 엔지니어용 `🌱 입문 요약` 기본 vs 공정 기술 수석용 `전체 심층` 기본 디폴트 선택.
  8. **UI 테마 프리셋**:
     - `라이트 모드` / `다크 모드` / `시스템 설정 동기화`.

## 2. 좌측 사이드바 (Sidebar) - 4대 작업실 연동 뷰

상단에서 선택한 탭에 따라 좌측 사이드바의 탐색 메뉴가 Transitions.dev 기반으로 동적 전환됩니다.

### 2.1 위키 본문 탐색 사이드바 (`#sidebar-wiki-view`)
- **기대 기능 (Requirements)**:
  1. **듀얼 모드 토글**: `🏛️ 업무 분야별 (4축)` ⟷ `📐 물리 규모별 (5단계)` 원클릭 전환.
  2. **4대 도메인 패싯 탭 (업무 분야 4축 - MECE 밸류체인 구조)**:
     - **소자·제품군 (Devices)**: HBM 3D 적층, 3D V-NAND, 2nm GAA 나노시트, 10nm급 DRAM
     - **제조 단위 공정 (Unit Process)**: 8대 공정 (웨이퍼 제조 ~ 첨단 패키징)
     - **팹 지능화 & 운영 (Operations)**: FDC(이상감지), APC(R2R), 수율 모델링(YMS), 장비 통신(EES/RMS)
     - **소재·인프라 (Materials & Infra)**: 팹 유틸리티(초순수, 스크러버), 첨단 슬러리(CMP), ALD 전구체
  3. **단위 공정/분야 아코디언 트리**: 분야 클릭 시 하위 개념 목록이 부드럽게 전개되고, 특정 개념 클릭 시 메인 위키 본문이 해당 개념으로 갱신된다 (선택된 개념에 포커스 하이라이트 유지).
  4. **물리 규모(Scale) 5단계 계층 트리**:
     - **Scale 5: 팹 인프라 & 유틸리티 (1km ~ 10m)**: 초순수 공급망, 서브팹 스크러버, 클린룸
     - **Scale 4: 설비 & 챔버 하드웨어 (10m ~ 1m)**: EUV 노광 스캐너, RIE 플라즈마 챔버
     - **Scale 3: 단위 공정 & 웨이퍼 런 (1m ~ 100nm)**: 300mm 웨이퍼 기판, 런 단위 식각/증착 레시피
     - **Scale 2: 소자 구조 & 나노 피처 (100nm ~ 1nm)**: GAA 나노시트 채널, 커패시터, 비트라인 에어갭
     - **Scale 1: 원자·분자 & 계면 화학 (< 1nm)**: 라디칼 화학흡착, 이온 충돌 스퍼터링, 격자 결함
     - 각 스케일 클릭 시 해당 물리 크기 범위에 귀속된 개념들만 필터링되어 노출된다.

---

### 2.2 기술 대안 비교분석 사이드바 (`#sidebar-ai-view`)
- **기대 기능 (Requirements)**:
  1. **연구 자산 관리형 세션 히스토리**:
     - **⭐ 즐겨찾기(Bookmark)**: 중요한 비교 세션(예: "HBM3E vs HBM4 방열")을 별표 클릭하여 상단 고정(Pinned).
     - **🗑️ 세션 삭제**: 일회성 테스트 질의는 호버 시 휴지통 아이콘으로 개별 삭제 가능.
     - **📁 프로젝트별 세션 폴더화**: `+ 새 폴더` 버튼으로 엔지니어링 프로젝트(예: "HBM 패키징", "2nm GAA")별 폴더를 생성하고 세션을 드래그/분류하여 관리.
  2. **세션 원클릭 복원**:
     - 히스토리 카드 클릭 시 메인 캔버스에 당시의 질문 내용, 선택된 3대 분기 상태, 스냅샷 1~3, 도출된 다차원 비교 매트릭스 결과 카드가 즉시 복원된다.
  3. **기준 판본 메타**: 현재 비교 분석의 기준이 되는 온톨로지 지식 판본(`v2026.10`) 및 검증 출처 수 상시 표시.

### 2.3 검토·승인 센터 사이드바 (`#sidebar-review-view`)
- **기대 기능 (Requirements)**:
  1. **2-Segment 상태 분리 탭 (`[대기 중 (To-do)]` ⟷ `[승인 완료 이력 (History)]`)**:
     - **`대기 중` 탭**: 현재 전문가 심사가 필요한 티켓만 노출되며, 승인이 집행되면 대기 목록에서 즉시 사라져 업무 집중도를 유지한다.
     - **`승인 완료 이력` 탭**: 승인 완료된 티켓들이 보관되어, 과거에 누가 어떤 사유로 승인했는지 Diff 및 감사(Audit) 이력을 언제든 재열람할 수 있다.
  2. **티켓 카드 메타 표기**: 대상 개념명, 제안 건수, 작성자, 제출일시, 제안 유형(`신규 개념`, `관점 추가`, `파라미터 수정`) 배지 노출.
  3. **티켓 선택 시 메인 연동**: 티켓 클릭 시 우측 메인 검토 화면에 해당 티켓의 2-Pane Diff 및 에디터 데이터가 즉시 로드된다.

## 3. 메인 캔버스: 4대 핵심 워크스페이스

### 3.1 [Tab 1] 위키 본문 (`#view-wiki`)
공식 검증본(v1.2)을 열람하는 메인 문서 뷰입니다.
- **기대 기능 (Requirements)**:
  1. **팹 라이프사이클 파이프라인 바**:
     - 현재 선택된 도메인에 따라 웨이퍼 제조부터 첨단 패키징까지 가로 공정 플로우 칩을 표시.
     - 칩 클릭 시 해당 단위 공정의 앵커 위치로 부드럽게 스크롤 이동하며, 필요 시 접기/펼치기 지원.
  2. **개념 메타 헤더**:
     - 상단 브레드크럼(예: `제조 단위 공정 / 식각 공정 / 플라즈마 건식 식각`).
     - 국문 공식 명칭 + 영문 학술 명칭 + 현장 별칭(Aliases: `RIE, 건식 식각`).
     - 상태 배지 3종: `v1.2 검증` 배지, `Level` 배지, `Scale` 배지(클릭 시 하단 '4. 온톨로지 관계'의 물리적 규모 계층도로 앵커 이동).
     - 최종 승인 메타(승인일자, 최종 검토 전문가 표기).
  3. **통합 스티키 컨트롤 바 (Sticky Bar - Transitions.dev)**:
     - 스크롤 시 화면 상단에 달라붙으며, 상단 탑바와 자연스럽게 연결(Sentinel 기반 CLS=0 수납 애니메이션).
     - **적용 맥락 렌즈 탭**: `공통 기본 지식` ⟷ `도메인: 첨단 메모리` ⟷ `A사 HBM3E` ⟷ `B사 DRAM` 등 관점을 전환하면 3번 섹션의 실무 사례 카드가 동적으로 교체된다.
     - **열람 깊이 모드**: `전체 심층(L1~L3)` / `🌱 입문 요약(L1)` / `📘 공학 메커니즘(L2)` 버튼 클릭 시 본문 내 각 섹션의 표시 여부가 즉시 필터링된다.
  4. **본문 5대 표준 섹션**:
     - **1. 기본 설명 (Adopted Definition) [Level 1]**:
       - 산업 표준 및 학술 문헌에서 공식 채택된 백과사전식 정의 및 공정/소자 도입 목적.
     - **2. 핵심 원리 및 물리적 한계 (Accordion) [Level 2]**:
       - Transitions.dev 아코디언 컴포넌트로 구성되어 부드러운 펼침/접힘 지원.
       - 물리·화학적 소자 동작 및 반응 메커니즘, 공정 결함 위험 및 미세화 한계 요약.
     - **3. 적용 맥락 렌즈 및 실무 사례 (Adaptive Level 3 Card) [Level 3]**:
       - 특정 챔버나 FDC에 편향되지 않는 **도메인 독립적 적응형 실무 카드(Adaptive / Polymorphic Card)**로 렌더링.
       - **블록 ① 헤더**: 관점 배지 + 실무 사례 표제 + 관리 코드(사내 레시피 ID, JEDEC 규격, 룰셋 코드 등 - 없을 시 자동 생략).
       - **블록 ② 실무 적용 맥락 설명 (Context Narrative)**: 해당 특정 관점/라인/규격 환경에서 왜 이 조건이나 규칙이 적용되는지 2~3줄의 실무 배경 설명.
       - **블록 ③ 핵심 적용 기준 및 사양 (Key Specifications & Criteria)**: 특정 고정 표 서식 대신 글머리 기호(Bullet) 또는 Key-Value 그리드로 수치, 허용 기준, 레시피, 판정 조건 등을 명확히 전달하며, 각 항목 끝에 근거 출처 인라인 칩(`[E-01]`, `[E-03]`)을 연동.
       - **블록 ④ 현장 제약 및 트레이드오프 (Operational Constraints & Caveats)**: ⚠️ 주의/경고 콜아웃 박스로 해당 조건을 적용할 때의 한계(TAT 증가, 전력 소비, 세정 주기 단축 등), 위험 요인, 타 라인 전용 시 주의점을 명시.
       - **블록 ⑤ 기본 지식(Default) 안내 상태**: '공통 기본 지식' 렌즈 열람 중일 때는 빈 상자 대신 "현재는 산업 공통 표준 지식을 열람 중입니다. 상단 관점 탭에서 세부 프로젝트를 선택하시면 현장 규격이 표시됩니다" 안내와 함께 선택 가능한 관점 숏컷 버튼 제공.
     - **4. 온톨로지 관계 및 물리적 규모(Scale) 계층**:
       - 상단: 물리적 크기 5단계(Scale 1~5) 중 현재 개념의 위치를 나타내는 스케일 네비게이터 카드.
       - 하단: `is_a`(상위 개념), `part_of`(구성 부품/하위 시스템), `next_step`(후속 단위 공정) 인라인 링크 칩 (클릭 시 해당 개념 위키로 즉시 이동).
     - **5. 공식 검증 출처 원문 (Evidence References)**:
       - 해당 문서의 모든 근거가 귀속된 공식 출처(Lam 백서, Applied 핸드북, 사내 승인 문서 등) 카드 리스트.
       - 각 카드 내 원문 인용문(Quote) 및 외부 웹사이트/공식 보고서 직행 링크 제공.
  5. **조용한 피드백 액션 (Quiet Feedback)**:
     - 본문 최하단에 불변 문서 고유 ID(예: `concept-dry-etch-001`) 상시 표기.
     - `내용에 오류나 누락이 있나요? 수정·보완 제안` 버튼 클릭 시 간이 제안 모달(`[M-06]`)을 열어 3번 검토 큐로 현업 피드백을 전달.

### 3.2 [Tab 2] 기술 대안 비교분석 (`#view-ai`)
엔지니어의 현업 문제(Pain-point)를 대화형으로 구체화하고 다차원 비교 분석표를 도출하는 화면입니다.
기존의 요청과 결과가 혼재되어 발생하던 인지 과부하를 해소하기 위해, **`[화면 2-A: 조사·분석 요청실]`**과 **`[화면 2-B: 비교 결과 리포트]`**의 **2단계 독립 화면 분리(2-Stage View Flow)**로 구성됩니다.

- **[화면 2-A: 조사·분석 요청실] (Setup & Clarifier View)**:
  - **화면 목적**: 현업 엔지니어가 모호한 고민을 구체화하고 비교 대상과 파라미터를 확정하는 전용 공간 (결과 테이블이나 스냅샷 등이 노출되지 않아 질문 설계에 100% 집중).
  - **기대 기능 (Requirements)**:
    1. **질문 입력창 & 빠른 추천 칩**: 질문 입력창 + `💬 대화로 질문 구체화` 버튼 + 빠른 추천 검색어 칩 8종 (HBM 방열, Cryo 식각, High-NA, 에어갭, 본딩, FDC, GAA, 스크러버 등).
    2. **대화형 질문 구체화 스트림 (Conversational Clarifier)**: 모호한 질문(예: "HBM 열 문제") 입력 시 에이전트가 온톨로지 인과 그래프를 조회하여 **3대 공학 분기 카드**를 제시. 사용자가 원하는 분기 카드를 클릭하면 파라미터 태그가 자동 세팅됨.
    3. **현업 고민 템플릿 추천 영역**: 입력 키워드에 반응하는 공학적 상충(Trade-off) 템플릿 카드.
    4. **맥락 파라미터 태그 그룹**: 기준 대상 A, 대조 대상 B, 평가 도메인, 기준 판본을 원클릭으로 변경(모달/드롭다운 연동).
    5. **실행 CTA 버튼**: **`⚡ 비교 분석 실행 (결과 보기 ➔)`** 버튼 클릭 시 Transitions.dev 전환 애니메이션을 거쳐 [화면 2-B]로 부드럽게 이동.

- **[화면 2-B: 비교 결과 리포트] (Comparison Result View)**:
  - **화면 목적**: 도출된 다차원 비교 매트릭스를 넓은 화면에서 심도 있게 검토하고 검토 센터로 보내는 전용 리포트 화면.
  - **진입 경로**: [화면 2-A]에서 `⚡ 비교 분석 실행`을 누르거나, 좌측 사이드바 히스토리에서 과거 세션을 클릭했을 때 진입.
  - **기대 기능 (Requirements)**:
    1. **상단 서브 네비게이션 바**:
       - **`← 분석 조건 수정 / 다시 질문하기`** 버튼 (클릭 시 화면 2-A로 복귀하여 전제 조건 수정 가능).
       - 현재 분석 세션 표제 (예: `HBM3E 방열 대안: SK하이닉스 MR-MUF vs 마이크론 TC-NCF`).
       - 즐겨찾기(⭐) 토글 버튼 (클릭 시 좌측 사이드바에 Pinned 고정).
    2. **스냅샷 타임라인 바**:
       - `1. 공학 질문 확정` ➔ `2. 양산 조건 매핑 [✏️ 전제 수치 수정]` ➔ `3. 다차원 비교 분석 완료` 단계별 과거 시점 이동 지원.
       - **🌟 스냅샷 2: [AI 파라미터 튜닝 상담자 (수치 조정 질문자)] 연동**:
         - 엔지니어가 수치가 아닌 설비 제약이나 변경 의도(예: "우리 라인은 가압력을 150N 이상 못 주는데 어떻게 조정하지?", "12단 적층 기준으로 조건을 완화하고 싶어")를 자연어로 질문.
         - AI 질문자가 온톨로지 물리 인과 모델을 기반으로 **보상 수치 조합(추천안 A, 추천안 B)과 트레이드오프(TAT 증가, Warpage 등)를 역제안**.
         - `[👉 이 수치 세트로 자동 반영 & 재실행]` 버튼 클릭 시 전제 수치가 자동 업데이트되고 새로운 비교 매트릭스가 즉시 재실행됨.
    3. **다차원 비교 매트릭스 테이블 (Full Width)**:
       - 전체 화면 폭을 활용한 대조표: 비교 분석 축(접합 방식, 열전도율, 결함률, 공정 TAT 등) ⟷ 기준 대상 A ⟷ 대조 대상 B.
    4. **AI 종합 인과 분석 코멘트**: 공학적 상충관계(Trade-off) 및 물리적 한계 요약.
    5. **거버넌스 연동 배너 (온톨로지 보완 제안 자동 도출)**:
       - 비교 분석 중 온톨로지에 누락된 신규 규격·결함 데이터가 발견된 경우 요약 노출.
       - **`✍️ 이 분석 결과를 검토 센터로 전송하여 온톨로지에 반영하기 ➔`** 클릭 시 3번 [Tab 3] 검토·승인 센터 큐에 티켓을 자동 등록하고 검토 센터 탭으로 즉시 전환.

### 3.3 [Tab 3] 검토·승인 센터 (`#view-review`)
제안된 기술 지식을 검토·보완하여 공식 위키에 승인·배포하는 거버넌스 화면입니다.
- **기대 기능 (Requirements)**:
  1. **검토 헤더 및 4대 핵심 액션 버튼**:
     - 개념명, 제안 건수, 작성자, 제출일시 메타 표기.
     - `✏️ 직접 편집 모드` 토글: 읽기/비교 뷰 ⟷ 직접 편집기 전환 (Transitions.dev 애니메이션).
     - `👁️ 반영될 위키 페이지 미리보기` 버튼: `[M-03]` 미리보기 모달을 호출하여 최종 반영된 위키 페이지 전체 모습을 열람.
     - `📖 반영된 위키 문서 바로가기` 버튼: 승인 집행 완료 후 활성화되며, 클릭 시 1번 [Tab 1] 위키 본문의 해당 문서로 즉시 이동.
     - `승인 및 공용 위키에 즉시 게시` 버튼: 최종 승인을 집행하고 `[M-04]` 확인 모달 호출. 사이드바 큐에서 '대기 중' 티켓이 제거되어 '승인 완료 이력'으로 자동 이동.
  2. **실시간 자동 무결성 점검 리포트 바 (AI Pre-validation)**:
     - `출처 일치도`: 인용된 공인 문헌 및 규격과의 부합율 실시간 검증(예: 100%).
     - `온톨로지 충돌 여부`: 상하위 스케일 및 인과 관계 모순 발생 여부(예: 충돌 없음).
     - `영향 범위`: 본문 변경 시 영향을 받는 연관 개념 수(예: 1건).
  3. **2-Pane Diff 및 전문가 직접 편집기 (In-Place Editor)**:
     - 좌측: 현재 공식 위키에 게시된 버전 (v1.2).
     - 우측 1: AI 통합 반영 초안 (제안 병합본) + 변경 항목 인라인 하이라이트(초록/노랑) + `👁️ 위키 미리보기` 칩.
     - 우측 2 (직접 편집 모드 시): 전문가 직접 수정용 `In-Place Editor Textarea` + `💾 수정 내용 초안에 반영` / `취소` 버튼.
  4. **에이전트에게 초안 보완 지시 (Directive Box)**:
     - 자연어 지시 입력창 + `🚀 수정 지시 전송` 버튼 + 빠른 요청 칩 4종 (극저온 배기 한계 추가, 출처 표기 공식화, 초심자 비유 보강, Scale 2 소자 연계 추가 등).
     - 지시 전송 시 원문 근거와 온톨로지 무결성을 유지하면서 초안을 재작성하여 우측 Pane에 반영.

### 3.4 [Tab 4] 외부 문헌·백서 조사 (`#view-investigation`)
위키에 미등록된 차세대 기술이나 최신 표준 규격을 글로벌 선도사 백서 및 국제 표준(SEMI/IEEE)에서 심층 조사하고 온톨로지 지식으로 합성하는 워크스페이스입니다.
[Tab 2]와 동일한 UX 통일성을 위해, **`[화면 4-A: 문헌 발굴 및 근거 피드]`**와 **`[화면 4-B: 종합 분석 리포트 & 지식 후보]`**의 **2단계 독립 화면 분리(2-Stage View Flow)**로 구성됩니다.

- **[화면 4-A: 문헌 발굴 및 근거 피드] (Literature Discovery View)**:
  - **화면 목적**: 기술 주제를 검색하고, 신뢰 출처 풀에서 교차 발굴된 공인 문헌(백서, 논문, 표준) 목록과 원문 인용구를 명확히 확인하는 전용 공간.
  - **기대 기능 (Requirements)**:
    1. **신뢰 출처 풀 안내 배너**:
       - 인터넷의 비공인 웹 문서를 배제하고, 삼성/SK하이닉스 기술자료, ASML 백서, Lam/AMAT 핸드북, SEMI 국제 표준, IEEE 학술 논문 등 검증된 5대 기관 출처 풀만을 대상으로 조사함을 명시.
    2. **기술 주제 조사 입력창 & 추천 칩**:
       - 조사 주제 입력창 + `🔍 문헌 발굴` 버튼 + 빠른 추천 검색어 칩 3종(차세대 유리기판 TGV, High-NA CNT 펠리클, 극저온 저탄소 대체 가스 등).
    3. **발굴된 공인 문헌 카드 피드 (Evidence Feed)**:
       - 에이전트가 신뢰 출처 풀에서 발굴한 3~4건의 핵심 공인 문헌 카드 리스트 노출.
       - 각 카드별 문서명, 발행일, 출처 유형 배지(`공식 기업 백서`, `Tier 3 공인 학술`, `SEMI 국제 표준`), 핵심 인용문(Quote), 외부 DOI/공식 웹사이트 직행 링크 제공.
    4. **종합 리포트 생성 CTA 버튼**:
       - **`📊 이 문헌들로 종합 분석 리포트 생성 (리포트 보기 ➔)`** 버튼 클릭 시 Transitions.dev 전환 애니메이션을 거쳐 [화면 4-B]로 부드럽게 이동.

- **[화면 4-B: 종합 분석 리포트 & 지식 후보] (Synthesis Report & Drafts View)**:
  - **화면 목적**: 발굴된 문헌들을 교차 분석한 종합 기술 리포트를 넓은 화면에서 여유롭게 열람하고, 도출된 온톨로지 신규 지식 후보를 확인하여 검토 센터로 등록하는 전용 리포트 화면.
  - **진입 경로**: [화면 4-A]에서 `📊 종합 분석 리포트 생성`을 누르거나, 좌측 사이드바 히스토리에서 과거 조사 로그를 클릭했을 때 진입.
  - **기대 기능 (Requirements)**:
    1. **상단 서브 네비게이션 바**:
       - **`← 발굴 문헌 목록으로 돌아가기`** 버튼 (클릭 시 화면 4-A로 복귀하여 다른 문헌 탐색 및 검색어 수정 가능).
       - 현재 리포트 표제 (예: `차세대 유리기판 TGV 공정 및 인프라 표준 종합 분석`).
    2. **문헌 종합 분석 리포트 (Full Width)**:
       - 전체 화면 폭을 활용한 가독성 높은 기술 브리핑: 공학적 도입 배경, 물리적 메커니즘, 양산 수율 한계 및 결함 위험, 주요 공정 파라미터 대조 요약.
    3. **도출된 온톨로지 지식 후보 카드**:
       - 에이전트가 문헌을 바탕으로 자동 정형화한 신규 온톨로지 지식 후보 2~3건 카드(예: `후보 1: 유리기판 TGV 공정 및 물성 규격`, `후보 2: 글래스 코어 기판 팹 인프라 및 안전 통제 규격`).
       - 각 후보 카드 내 핵심 규격 요약 및 근거 출처 칩 표시.
    4. **선택적 검토 센터 이관 액션**:
       - 각 후보 카드 하단의 **`[ ✍️ 검토 센터 큐에 등록 ]`** 버튼을 누르면 해당 지식이 3번 [Tab 3] 검토·승인 센터의 [대기 중] 목록으로 자동 등록되고, 등록 완료 토스트 알림 제공.

## 4. 오버레이 드로어, 팝오버, 모달 6종

### 4.1 [D-01] 근거(Evidence) 원문 리더 슬라이드 드로어 (`#evidence-drawer`)
- **기대 기능**: 위키 본문의 `[E-01]`, `[E-02]` 클릭 시 우측에서 슬라이드인. 출처명, 발행일, 공인 규격 원문 인용문, 외부 DOI/웹사이트 직행 링크 표시.

### 4.2 [P-01] 인라인 등록 개념 팝오버 (`#concept-popover`)
- **기대 기능**: 본문 내 점선 링크 호버 시 $200\text{ms}$ 디바운스 후 팝오버 카드 표시. 개념명, 요약 정의, `💡 문맥 맞춤 해설` 카드 제공 (주변 공정 및 문맥에서 해당 개념이 수행하는 구체적 역할과 의미 해설).

### 4.3 [M-01] 전역 스포트라이트 검색 모달 (`#search-modal`)
- **기대 기능**: `Cmd+K` 호출. 개념명, 영문, 약어(EUV, ALE, ZAZ 등) 실시간 검색, 키보드 방향키(`↑`, `↓`) 및 `Enter` 이동 지원.

### 4.4 [M-02] 위키 페이지 승인 반영 실시간 미리보기 모달 (`#modal-wiki-preview`)
- **기대 기능**: 검토 센터에서 승인 시 1번 공용 위키가 어떻게 렌더링될지 보여주는 대형 모달. **✨ 변경 항목 하이라이트 토글**(추가분 초록, 수정분 노랑), 모달 내 최종 승인 버튼 포함.

### 4.5 [M-03] 승인 성공 확인 모달 (`#approval-success-modal`)
- **기대 기능**: 승인 집행 완료 시 표시되는 모프 체크 애니메이션 모달. `v1.3` 정식 승인 안내 및 1번 위키 바로가기 제공.

### 4.6 [M-04] 전제 파라미터 수정 및 AI 튜닝 상담 모달 (`#edit-params-modal`)
- **기대 기능**:
  - 스냅샷 2 시점에서 호출되는 모달.
  - **AI 파라미터 질문자(상담관)**: 엔지니어가 "가압력을 20% 줄이면 어떻게 해야 하지?" 등 자연어로 질문 시 온톨로지 인과 모델을 기반으로 2~3가지 추천 수치 세트와 트레이드오프를 역제안.
  - **원클릭 자동 반영**: 추천안 클릭 시 전제 파라미터 폼에 즉시 주입 및 재실행.
  - **수동 미세조정(Manual Tuning) 폼**: 직접 숫자를 수정하길 원하는 엔지니어를 위한 접이식 인풋 필드 겸비.

### 4.7 [M-05] 내용 보완 및 수정 제안 모달 (`#suggest-modal`)
- **기대 기능**: 위키 본문 하단 피드백 클릭 시 오픈. 현업 공정 조건 및 결함 사례를 작성하여 3번 검토 큐로 전송.
