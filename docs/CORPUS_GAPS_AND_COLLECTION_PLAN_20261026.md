- 근거 유형: 실측·시뮬레이션·모델 추정·업체 주장·편집 요약을 구분하고, 수명 외삽과 실제 관측 기간도 나눕니다.

## 실행 순서와 완료 기준

### 기존 자료 정비

실제 제목과 본문 구간을 식별하고, 영상 소개·부분 수집·편집 요약·번역 관계를 목록화합니다. 서지 불일치와 원출처가 없는 수치는 우선 검토 대상으로 둡니다. 원본은 보존하고 복구·정정한 본문은 새 판본 또는 명시적인 파생 문서로 관리합니다. 이 단계의 결과는 ‘보유하지만 미반영’, ‘다시 확보할 본문·도표’, ‘새로 수집할 근거’ 목록입니다.

### 본딩 질문부터 작은 시범 수집

최근 대화의 TCB 원리·적용 조건, TSV/와이어 전력, 본딩 결함·신뢰성 질문을 시작 범위로 삼습니다. 위 후보에서 원문을 확보하고, 조건을 실제로 추가하는 문헌부터 검토합니다. 특정 사이트의 홍보 설명만 반복된다면 다른 독립 원논문으로 이동합니다. 숫자만 있는 자료나 동일 출처의 재서술을 더 모으는 것으로 완료하지 않습니다.

### 서비스 반영과 질문 재확인

검토한 자료만 기존 경로인 **문헌 등록 → 검토 → 승인 → 선택 문헌 즉시 색인 → 작업 완료 확인 → 같은 대표 질문** 순서로 반영합니다. 일반 파일 등록은 2MB 이하 Markdown·텍스트이며, 공개 URL PDF 확보도 크기·페이지·시간 제한이 있습니다. Office·OCR·모든 표 해석이 이미 지원된다고 가정하지 않습니다. 등록·승인·검색 반영 상태를 각각 확인합니다.

완료 기준은 문헌 개수가 아니라 아래처럼 답변 범위가 구체적으로 바뀌는 것입니다.

- TCB 질문은 재료와 접합 구조를 명시한 원리 및 실제 문헌의 조건·한계를 출처와 함께 설명할 수 있어야 합니다.
- 조건 비교 표는 각 셀을 원문의 시험 조건·표·그림으로 추적할 수 있어야 합니다. 조건이 다른 실험의 값을 한 공정창으로 합치지 않습니다.
- 전력 비교는 같은 경계와 조건의 근거가 확보된 경우에만 계산합니다. 충분하지 않으면 W·pJ/bit·절감률을 여전히 미확인으로 표시하는 것이 정상입니다.
- 신뢰성 질문은 시험 조건·고장 판정과 모델의 가정을 설명하고, 다른 구조나 양산 제품으로 일반화할 수 없는 부분을 표시해야 합니다.
- 출처별 설명은 업체의 공식 자료와 외부 전문가 발언·연구 결과를 구분해야 합니다. 색인 성공과 의미 정확성 검토도 별도로 판단합니다.

### 범위를 넓히는 조건

본딩 시범 수집으로 원문 추적과 질문 확인 절차가 정리되면 전공정 공정창·장비 사양·메모리 벤치마크로 확장합니다. 본문에 접근하지 못했거나, 같은 조건의 실험을 찾지 못했거나, 새로운 후보가 같은 설명만 반복하면 해당 부족 상태를 남기고 검색을 종료합니다. 재검색을 무한 반복하거나 다른 모델의 상식으로 메우지 않습니다.

## 이번 조사에서 확인하지 않은 범위
