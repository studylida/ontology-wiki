## 시각 확인과 수정

최신 `frontend-live-01`부터 `09`·`09b`는 완료된 실제 답변을 GET으로 복원한 이미지입니다. 생성 모델과 임베딩 모델의 합계 값 `multiple`이 생성 모델로 보이지 않도록 실행 정보 표시를 고쳤습니다. 요청·반환 모델, effort·서비스 등급, 호출별 토큰·비용을 분리했습니다. 내부 출처 ID는 실제 citation 목록에 연결된 번호로 표시합니다. 관계 방향을 유지하며 관계 유형을 한국어로 표시하고, 여러 개념에 대한 카드를 같은 개념의 관점이라고 설명하지 않습니다. 분석 비교표 첫 열이 한 글자씩 줄바꿈되지 않도록 최소 폭을 주었습니다. 개인 위키 목록 대기 중에는 조회 중 상태를 표시합니다.

`frontend-live-10`·`11`·`12`는 실제 스트림·재연결·취소 때 찍은 원래 기록입니다. 이 실행에서 긴 출처 목록이 먼저 도착하면 스크롤이 본문 아래로 이동하는 문제를 확인했습니다. 이후 자동 스크롤의 기준을 생성된 마지막 본문 블록으로 바꾸고 2개 DOM 회귀 테스트를 추가했습니다. 최종 `frontend-live-13-partial-body-in-view.png`는 새 창에서 실제 취소 답변을 GET 복원했을 때 본문이 처음부터 읽기 영역에 보이는 것을 검증한 이미지입니다. 수정 후 추가 유료 생성은 수행하지 않았습니다.

대표 데스크톱·모바일 이미지는 `../browser-desktop.png`, `../browser-mobile.png`에도 반영했습니다. 이전 Fixture 결과는 별도 기록으로 유지합니다.

## 공개 기록 범위와 남은 한계

이 JSON은 인증 정보·키·요청 헤더·원문 전체를 포함하지 않습니다. 공급자의 request/response ID와 raw 응답 메타데이터는 공개본에서 제외했습니다. 앱 내부 run·message·source ID, 검증 단계, 실제 계측·사용량·상태는 추적을 위해 남겼습니다. 이미지의 문헌과 생성 내용은 위에서 확인한 공개 자료에 대한 테스트 결과입니다.

이 브라우저 검증은 문헌의 공식성이나 모든 생성 주장의 의미 정확성을 증명하지 않습니다. 외부 문헌 조사 품질, 운영 부하, 모든 접근성 기준, 다양한 장기 연결 장애는 별도 검증 대상입니다. 서로 다른 개념의 관점 카드가 함께 있는 이 위키 답변에는 “등록 관점 조회” 버튼이 제공되지 않아 그 명시적 GET을 실제 화면에서 실행하지 않았습니다. 후속 질문 준비와 로컬 필터, 단위 테스트의 호출 경계까지 확인한 것으로 한정합니다.
