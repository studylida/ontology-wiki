# 관련 문헌 8개로 비교한 기존 RAG와 LightRAG — 2026-10-27

후속 결정: 사용자가 LightRAG 완전 제거를 지시했다. 아래는 제거 전 실행 기록이다. 제품 연결·의존성·빌드 코드·설정과 전용 DB는 제거했다. 전용 그래프 파일·격리 런타임 삭제는 자동 승인 정책에 차단돼 남아 있다([제거 상태](LIGHTRAG_REMOVAL_20261027.md)). 원문·판본·기존 벡터 및 이 비교 기록은 보존한다. 그래프 감사·사용량·요약은 `var/rag-evaluation/20261027/lightrag-removal-audit/`로 보존하므로 아래의 옛 그래프 경로를 활성 실행 환경으로 사용하지 않는다.

**이 두 질문에서는 기존 RAG를 유지하는 것을 권한다.** 관련 문헌만 소규모 색인하면 같은 자료로 비교할 수 있었다. 이전 보고서에서 전체 색인 불일치를 이유로 비교를 끝낸 판단은 범위 설정이 불충분했다.

## 동일 조건

TSV 구조·에너지·지연·검출기 제작 한계, 열압착 개요·Au–Au 원리·Cu 막 두께 실험에 관한 기존 승인 문헌 8개를 실행 전에 고정했다. 각 문헌의 저장된 전체 구간을 사용해 총 94구간·103,392자다. 원본·판본·전처리 결과·기존 앱 임베딩은 재사용했다. 두 경로 모두 동일한 8문헌에서 벡터·문자 검색, CrossEncoder, 주변 조건 보충을 사용하고 LightRAG 추가 검색만 켜고 껐다.

같은 코드 `fc8570e`, 생성 모델 `gpt-6-luna`, effort `medium`, 빈 대화 이력, 같은 질문 순서를 사용했다. corpus hash는 `d8b9e1ea7623128e0fbf3b86586fa79df477a95e89d391574f406c029721cc96`, backend code hash는 `26ef7170ce2f2bbccca45cf0fb5de5cc0e50af172fba3bd24abfa54d861e994d`로 양쪽이 일치한다. 각 경로에서 첫 TSV 질문은 GPU 모델 최초 로딩 약 12초를 포함하고 두 번째 질문은 준비된 모델을 사용했다. 아래 시간은 검색·생성 하니스의 처리 시간으로 HTTP·화면 렌더링 시간은 포함하지 않는다.

LightRAG 쪽 전체 API 추정 비용이 낮은 것은 반복한 동일 입력의 캐시 적중과 생성 길이 차이가 섞인 결과다. 실제 생성 입력의 cached tokens는 TSV가 기존 1,158→추가 6,892, 열압착이 1,058→5,263이었다. 이를 그래프가 생성 비용을 줄인 효과라고 해석하지 않는다. 그래프 조회가 추가한 추정 비용은 두 질문 합계 $0.00028788이다. 모든 달러 비용은 공급자 사용량과 기록된 가격에 따른 추정이며 로컬 GPU·전기 비용은 측정하지 않았다.

소규모 그래프 구축은 340.563초(5분 41초), 186회 호출, 추정 $0.12779332였다. 오류·사용량 미확인 건은 없었다. 구축비와 질문 처리비는 별도다. 이번 네 답변의 검색·생성 비용은 합계 $0.005755465이고 구축을 포함하면 $0.133548785다. 과거의 전체 구축·중단 비용은 이 소규모 실험 비용에 합치지 않는다.

## 근거 검색과 답변 정확성

두 질문 모두 최종 선택된 근거 구간의 집합·순서뿐 아니라 **생성 모델에 전달된 최종 prompt hash까지 완전히 같았다.** 따라서 답변 문장의 차이를 LightRAG가 더 나은 근거를 찾아낸 효과로 볼 수 없다.

- TSV: 그래프가 반환한 23개 구간은 모두 기존 벡터·문자 검색 후보와 중복됐다. 양쪽 답변의 공정 노드별 핀 간·버스 에너지 수치 16개는 원문 표와 일치하고 pJ/bit를 W로 바꾸지 않았다. 두 답변 모두 요청하지 않은 지연 수치 부재 설명과 자료 소개형 문장이 남았다.
- 열압착: 그래프가 반환한 24개 중 9개는 벡터·문자 검색 후보에 없었지만 ThruChip·검출기 ASIC 구간이어서 최종 후보 60개에 들지 않았다. 열압착에 필요한 새 조건 구간은 추가하지 못했다. 양쪽이 인용한 250°C·0.5시간 접합률 31.24/61.14/93.06% 등은 원문과 일치하고 인용 ID도 정상이다. 그러나 그 결과에 대응하는 막 두께 0.8/2.0/2.7µm의 시편 정의 구간은 양쪽 생성 입력 모두 빠져 있어 실험 설명이 불완전했다. 기존 RAG 답변의 1시간 접합률 69.75/86.66/95.10%도 표와 일치하지만 같은 시편 조건 누락 문제가 있다.

즉 LightRAG는 이 소규모 비교에서 최종 근거를 개선하지 않았고, 관찰한 조건 누락이나 문체 문제도 해결하지 않았다. 그 한계까지 포함해 기존 RAG 유지 권고를 내린다. 문체나 조건 검색이 완성됐다는 뜻은 아니다.

## 보존과 재현

실험 그래프만 `var/lightrag/experiments/two-question-20261027/`에 만들었다. 8개 문헌·94개 구간의 판본·본문 해시 및 현재 승인 snapshot 일치를 확인했고, 기존 서비스용 active50과 중단된 199개 checkpoint·원본 문헌·판본은 모두 보존했다. 이 실험을 이유로 전체 구축을 재개하거나 서비스 기본 검색 경로를 바꾸지 않았다.

실행 근거는 `var/rag-evaluation/20261027/subset-comparison/`의 `selection.json`, `corpus-manifest.json`, `off/results.json`, `on/results.json`과 비교·trace 기록이다. 그래프 구축·무결성 근거는 별도 실험 경로의 `ready-audit.json`과 `active.json`에 있다. trace는 구간 ID·순서·단계만 복사하고 실제 반환값과 호출은 바꾸지 않았다. 추가 RAGChecker나 다른 질문은 실행하지 않았다.

두 질문을 각 경로에서 한 번씩 실행한 소규모 대조이며, 다른 관계 탐색 질문이나 큰 자료집에 대한 LightRAG의 일반적인 성능은 검증하지 않았다.
