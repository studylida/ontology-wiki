# 반도체 코퍼스 품질 개선 작업 기록

이번 작업은 기존 제공 문헌을 보존하면서 잘못되거나 조건이 없는 설명을 분리하고, 신뢰 가능한 출처의 직접 근거를 찾기 위한 오프라인 자료 정비입니다. 2026-10-27 재개 실행의 자료와 검토 기록은 저장소의 `var/corpus-quality/20261026T073106Z`에 있습니다. 이 보고서는 제품 서비스의 데이터 등록이나 성능 검증 보고서가 아닙니다.

원본 ZIP SHA-256은 `2b4c1e438414d10f997b7460112270329547d1c5fea97fd925453e4caac9117d`이며 제공 문헌 129건의 해시와 원본 사본을 별도로 보존했습니다. 112건은 정성 설명 중심의 조건부 파생 후보이고 17건은 원출처나 본문 부족으로 보류했습니다. 한영 문헌 두 쌍은 각각 같은 계보입니다. 파생본에서 오류·상충·조건 부족으로 분리한 주장과 구절은 121건이며 원본에서 삭제하지 않았습니다.

삼성 기사·용어 자료 78건의 20자 이상 본문 309줄과 삼성 8대 공정 9건의 132개 본문 블록을 발행 페이지와 기계적으로 대조했습니다. 정규화한 텍스트 일치와 내용의 진위·최신성·도표 보존·권리 검증은 서로 다릅니다. 독립적으로 내용과 수정 구절을 살핀 문서와 범위는 각 검토 보고서에 명시했습니다.

물의 분자량과 순수 알루미늄 녹는점, FWC와 플럭스, 실리콘 전도성, CVD, EUV 마스크와 감광제, GEMM, RAM·ROM, LED 광추출효율과 관련한 문제를 근거와 함께 보류하거나 별도 편집 주석으로 바로잡았습니다. 상충하는 Lam 장비 치수와 논문 DOI, 원 자료의 잘못된 단위·비교 조건은 원본을 바꾸지 않고 보류했습니다. 신규 출처 29건 중 11건은 CC BY 출처 표시와 독립 검토를 마친 제한적 로컬 편집 요약이고 11건은 조건부 후보, 7건은 근거·조건 또는 전문 부족으로 보류했습니다. 로컬 요약의 수용은 실서비스 반입이나 제3자 도판 배포 승인을 의미하지 않습니다.

TCB의 실제 조건과 열사이클 관찰, CMP와 접합계면, ALD 성장률, HBM2 전력, MR-MUF 단계와 TSV 관련 모델·측정 사례를 원문 위치와 시험 범위에 연결했습니다. TSV와 와이어 본딩의 전력 차이를 전압·속도·부하·길이·채널이 일치하는 보편적 절감률로 확정할 직접 근거는 찾지 못했습니다. 서로 다른 DRAM의 정규화된 I/O 수치나 PCB 대비 모델을 그 수치로 전환하면 안 됩니다.

예를 들어 [Cu 범프 열사이클 연구](https://doi.org/10.3390/ma14195522)는 특정 구조의 접합 조건과 시험 결과를 함께 제시합니다. [TSV 정전용량 연구](https://doi.org/10.3390/mi16070750)는 개별 TSV의 약 738 fF를 보고하지만 그 수치의 정확한 편향점과 시험 주파수·표본 수는 확인되지 않았습니다. 이 값은 와이어 본딩과의 전력 차이나 보편적인 TSV 사양이 아닙니다. 각 요약은 원문 위치와 확인된 한계를 함께 보존합니다.

다음 자료 수집에서는 동일한 드라이버·전압·데이터율·부하·채널과 측정 경계에서 TSV 및 완성된 와이어 연결을 비교한 실험 또는 재현 가능한 모델을 우선합니다. TCB의 솔더 재료별 접합 조건, 양산 구조에 가까운 신뢰성 표본, 식각·산화의 공정 변수와 결과도 추가로 필요합니다. 제품에 반입할 때는 이용 범위와 기존 문헌·리비전의 중복을 다시 확인하고 고정 질문에 대한 실제 검색·인용 평가를 별도로 수행해야 합니다.

통합 문헌·주장 목록은 해당 실행 폴더의 `inventory.jsonl`과 `claims.jsonl`, 고정된 12개 질문의 전후 비교는 `evaluation.md`, 상세 인계는 `handoff.md`입니다. `review/`에는 문헌·주장별 출처, 독립 내용 검토, DOI 불일치, 원문과 파생본의 해시, 테스트 및 수정 전 백업이 있습니다. 개별 후보 본문에 남은 ‘독립 검토 대기’는 작성 시점 표기이며 통합 목록의 해시 연결된 독립 검토 상태가 최신입니다.

정리 도구 `scripts/v2/curate_existing_corpus.py`는 129개 입력의 해시와 실행 시각·사용량 체크포인트를 확인하고, 비어 있는 별도 실행 폴더에만 파생본을 만듭니다. 제공 원문 구절이 포함된 교정 규칙 `curation-rules.json`, 원문과 파생 자료는 Git 제외 폴더에 보관합니다. 규칙의 SHA-256은 실행 폴더의 `run-control.json`에 있으며 값이 일치하지 않으면 정리를 중단합니다. 재실행하려면 사용자가 승인한 유효한 실행 제한과 원본 매니페스트·원본 사본·규칙·물성 근거가 포함된 새 실행 폴더를 사용해야 합니다. 기존 실행 결과를 대상으로 스크립트를 돌리지 않습니다.

Python 3.11과 3.12의 별도 테스트 폴더에서 파생 Markdown 113개와 목록 3개가 기존 결과와 바이트 단위로 일치했습니다. 최적화 실행에서도 기존 출력과 변조된 규칙을 거부했고, 실제 Windows 정션으로 연결된 입력·출력 경로를 차단했습니다. 정리 스크립트는 실행 시작 시점에만 사용량·시각을 검사하므로 실행 중 제한은 바깥의 작업 감독이 관리해야 합니다.

이번 작업에서 서비스의 생성·임베딩 API 호출, 자료 등록·철회·승인·색인 및 제품 DB 변경은 하지 않았습니다. 이 결과로 실제 검색 정확도나 답변 품질이 개선됐다고 단정할 수 없으며, 다음 반입 단계에서는 사용 권한과 제품 내 평가가 별도로 필요합니다.
