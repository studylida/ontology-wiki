# 답변에 필요한 근거와 원리 구간 보강

이전 다섯 질문 평가에서 TSV 비교는 전력·지연이 아닌 검출기 분해능 연구의 비교 한계를 덧붙였고, 열압착 질문은 실제 보유한 금 접합 원리 구간을 찾지 못했다. 두 문제를 개별 답변이나 출처 ID에 맞춘 규칙으로 수정하지 않았다.

원리 구간은 최초 후보 52위였지만 여러 질의의 융합 상위 60개에서 빠졌다. 저장된 후보를 재정렬하면 전체 후보 82개 중 7위였다. 원리 질문에 한해 후보를 최대 두 배까지 살피고, 상위 후보를 각 요소의 작용과 변화 과정 중심으로 추가 재정렬해 다른 출처를 최대 하나 보충한다. 원문과 편집본, 기존 색인은 변경하지 않는다.

비교 질문은 지연·경로처럼 사용자가 요청한 항목을 별도로 계획하고, 답변 전 모델 검토에서 각 항목의 실제 관련 사실·조건과 출처 ID를 구조화한다. 출처 ID와 항목을 검증하고 기존 근거 전체도 답변 모델에 제공한다. 개별 실험의 한계는 그 실험 결과를 사용할 때 연결하도록 안내한다. 이 검토는 별도 공급자 호출이며, 파싱·호출이 실패하면 경고와 사용량을 남기고 기존 근거로 답한다. 순위·검토 결과 모두 오류가 있을 수 있어 사실 확인을 대체하지 않는다.

기존 문헌 199개를 사용한 실제 모델 예비 실행에서 열압착은 Au 접합 사례의 압력에 의한 표면 밀착과 열에 의한 확산을 편집 요약과 함께 인용했다. TSV 비교는 32 nm 비트당 에너지와 전력 단위 차이를 제시했고, 지연의 불필요한 수치 부재와 ASIC 연구 설명을 덧붙이지 않았다. 다만 일회성 생성 결과이며 항상 같은 품질을 보장하지 않는다. 예비 실행 기록은 로컬 `var/rag-evaluation/20261028/answer-quality-pipeline-diagnostic-v2/`에 있다.

기존 코드와 결합된 관련 검사 56개가 통과했다. 검토 호출의 사용량은 답변 사용량에 합산하고, 모델이 사용량을 보고하지 않으면 알 수 없는 비용으로 표시한다. `var/`의 평가 결과는 Git 추적 대상이 아니며 원격에는 코드와 이 기록만 전달된다.
