# 보존한 과거 데이터 자산

이 디렉터리의 JSON·원문 및 `golden_dataset.py`, `extended_concepts.py`의 리터럴 데이터는 과거 구현의 자료입니다. 새 서버가 자동 실행하거나 공용 RAG에 승인된 사실로 반입하지 않습니다. 원래 이름과 상태를 보존했으며 `golden`, `verified`, `adopted` 같은 과거 표기를 현재 전문가 인증으로 해석하지 마세요.

새 반입은 문헌 판본·출처·접근 범위 확인 후 별도 개발 DB에서 수행합니다. 과거 실제 운영 데이터는 제공되지 않아 이 seed가 운영 DB를 대표한다고 가정하지 않습니다. 자세한 이전 절차는 `docs/MIGRATION.md`를 참고하세요.
