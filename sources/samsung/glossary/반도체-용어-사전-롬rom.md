**롬(ROM)**
[Read Only Memory]

한 번 기록된 정보를 읽을 수만 있고 수정할 수 없는 메모리.

정보를 저장하는 용도로 사용되는 메모리 반도체는 크게 램(RAM)과 롬(ROM)으로 나뉜다. 롬은 ‘Read Only Memory’의 약자로 한 번 기록한 데이터를 빠른 속도로 읽을 수는 있지만, 기록 및 수정은 할 수 없다. 롬은 전원이 공급되지 않아도 기록된 정보가 지워지지 않으므로 비휘발성 메모리(Non-Volatile Memory)라고도 한다.

롬은 정보를 다시 쓰고 지울 수 있는 방식에 따라 MASK ROM, PROM, EPROM, Flash Memory 등으로 구분되는데 MASK ROM은 제조과정에서 미리 내용을 기록해 놓은 메모리로, 사용자가 내용을 수정할 수 없는 롬이다. PROM은 사용자가 한 번 기록할 수 있는 롬이고, EPROM은 필요 시 기억된 내용을 지우고 다른 내용을 기록할 수 있는 롬이다. 특히 EPROM은 전기적으로 정보를 기록하고 소자에 강한 자외선을 비추어 정보를 지울 수 있기 때문에 반복해서 여러 번 정보를 기록할 수 있는 것이 장점이다.

**※ 메모리 반도체의 종류**
