**PCI Express**
[PCIe, Peripheral Component Interconnect-Express]

기존 SATA 인터페이스의 초당 데이터 전송 속도의 성능 한계를 극복한 인터페이스 규격.

2002년 PCI SIG가 규정한 직렬 전송 방식의 인터페이스로 PATA, SATA에 이은 차세대 인터페이스이다. 현재까지 SATA 인터페이스의 데이터 전송 속도 한계는 600MB/s이지만, PCIe 인터페이스는 현재까지 초당 3GB/s의 데이터 고속 전송이 가능하다.
